# Broth3rsDev privacy policies

Privacy policies for every Broth3rsDev app, published with GitHub Pages at
<https://broth3rsdev.github.io/privacy_policy/>. One Markdown page per app and language; the
address without a language suffix is the one to paste into a store console, since it lets the
reader pick a language.

## Adding an app or a language

1. Copy an existing `<app>_privacy-policy-<lang>.md`, keep the front matter (`title`, `lang`) and
   the section order, and describe only what that app really stores, sends and asks permission for.
2. For more than one language, add an `<app>_privacy-policy.md` chooser page that links each one.
3. Add the app to `index.md` and to the lists above.
4. Push to `main`; GitHub Pages rebuilds the site from there.
